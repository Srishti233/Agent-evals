# Engineering Practices
Every pull request needs 2 approvals before it can be merged. The main branch is released every Thursday at 14:00 IST. Robot firmware is written in Rust, while fleet software uses Python and TypeScript. The on-call rotation lasts 7 days and engineers receive an on-call allowance of $350 per on-call week. A SEV1 incident requires a response within 15 minutes.
